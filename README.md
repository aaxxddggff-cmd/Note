# สมุดสิ่งสำคัญ

แอปจดสิ่งสำคัญพร้อมปฏิทิน ใช้แค่ Python standard library + SQLite ไม่ต้องติดตั้งอะไรเพิ่ม
โครงหน้าตามดีไซน์ https://claude.ai/artifact/Jrd67mSbgQXrxQRjy96fuQ (สีและฟอนต์ปรับเป็นแบบมินิมอล)

```sh
python3 server.py                            # http://localhost:8001
python3 server.py --users                    # รายชื่อบัญชี
python3 server.py --reset-password EMAIL     # ตั้งรหัสผ่านใหม่ให้บัญชี
python3 server.py --create-user EMAIL        # สร้างบัญชี (ใช้ได้แม้ปิดรับสมัคร)
python3 server.py --delete-user EMAIL
python3 server.py --reset                    # ลบข้อมูลและไฟล์แนบทั้งหมดแล้วเริ่มใหม่
python3 -m unittest discover -s tests -v     # รันเทสต์
pip install -r requirements.txt              # (ไม่บังคับ) เปิดการแจ้งเตือนแบบ push
```

**เอาขึ้นใช้งานจริงบน VPS:** ดู [DEPLOY.md](DEPLOY.md) (Docker + Caddy ทำ HTTPS อัตโนมัติ) และเช็กลิสต์ "ก่อนเปิดให้คนอื่นใช้"

- **หลายบัญชี:** ใครก็สมัครได้ด้วยอีเมลและรหัสผ่าน ข้อมูลของแต่ละบัญชีแยกกันทั้งหมด ปิดรับสมัครได้ด้วย `ALLOW_SIGNUP=0`
  ลืมรหัสผ่านได้รับลิงก์ทางอีเมล ถ้าตั้งค่า `SMTP_*` ไว้ ผู้ใช้ดาวน์โหลดข้อมูลของตัวเองหรือลบบัญชีได้เองในหน้าตั้งค่า
- **ความปลอดภัย:** รหัสผ่านเก็บแบบ PBKDF2 จำการเข้าสู่ระบบ 180 วัน จำกัดการล็อกอินผิดต่อ IP และต่ออีเมล จำกัดการสมัคร 5 บัญชีต่อ IP ต่อชั่วโมง
  ไฟล์แนบได้ 200 MB ต่อบัญชี (`USER_QUOTA_MB`) และมีหน้า `static/privacy.html` เป็นแม่แบบนโยบายความเป็นส่วนตัว ต้องเติมข้อมูลเองก่อนใช้จริง
- **ติดตั้งเป็นแอปได้ (PWA):** มี service worker ทำให้เปิดแอปและดูข้อมูลที่เคยโหลดไว้ได้แม้ออฟไลน์ (แต่ตอนออฟไลน์แก้ไขไม่ได้)
- **แจ้งเตือนแบบ push:** ถ้าติดตั้ง `pywebpush` ไว้ เซิร์ฟเวอร์จะเช็กทุกนาทีแล้วส่งแจ้งเตือนและสรุปเช้าไปที่เครื่องที่เจ้าของบัญชีเปิด "แจ้งเตือนบนเครื่องนี้" ไว้
  แม้ปิดแอปอยู่ก็ได้รับ
- **สำรองข้อมูลอัตโนมัติ:** ทำตอนเปิดเซิร์ฟเวอร์และทุก 24 ชม. เก็บไว้ที่ `backups/` 14 ชุดล่าสุด (สั่งเองได้ด้วย `python3 backup.py`)
- **ฐานข้อมูลจากเวอร์ชันก่อน:** อัปเกรดให้อัตโนมัติ ข้อมูลเดิมย้ายไปอยู่บัญชี `OWNER_EMAIL` (ค่าเริ่มต้น `owner@localhost`)

ใช้พอร์ต 8001 เพื่อไม่ชนกับน้ำเตือน (`~/Projeat1` ใช้พอร์ต 8000) ข้อมูลเก็บใน `data.db` ไฟล์แนบเก็บใน `uploads/`
ฟอนต์ Noto Sans Thai โหลดจาก Google Fonts ถ้าไม่มีอินเทอร์เน็ตจะใช้ฟอนต์ของเครื่องแทน

## หน้าต่าง ๆ

| | |
|---|---|
| **วันนี้** (`#/today`) | สรุปจำนวนเรื่องที่ยังไม่เสร็จ เลยกำหนด และอีก 7 วัน, เรื่องที่เลยกำหนดพร้อมปุ่ม “ย้ายมาวันนี้”, แถบ 7 วัน, รายการวันนี้, วันหยุดราชการที่ใกล้ถึง |
| **ปฏิทิน** (`#/calendar`) | ปฏิทินรายเดือน มีจุดสีตามหมวด วันหยุดและเสาร์อาทิตย์เป็นสีแดง กดวันเพื่อดูรายการ และติ๊กว่าเสร็จได้ ปุ่ม “ค้าง N เรื่อง” เปิดรายการเรื่องสำคัญ (`#/important`) |
| **สัปดาห์** (`#/week`) | 7 วันเรียงลงมา พร้อมความคืบหน้าของเช็กลิสต์และสรุปท้ายสัปดาห์ |
| **ค้นหา** (`#/search`) | ค้นในหัวข้อ โน้ต และเช็กลิสต์ กรองตามหมวดหรือ “เสร็จแล้ว” แบ่งเป็นกำลังจะถึงกับผ่านไปแล้ว และจำคำค้นล่าสุด |
| **รายละเอียด** (`#/note/<id>`) | แก้หัวข้อ วัน เวลา แจ้งเตือน การทำซ้ำ และหมวด, เช็กลิสต์ย่อย, โน้ต, ไฟล์แนบ (สูงสุด 10 MB ต่อไฟล์), เลื่อนไปพรุ่งนี้, ทำสำเนา, ลบ แก้แล้วบันทึกทันที |
| **ตั้งค่า** (`#/settings`) | เพิ่ม แก้ และลบหมวดหมู่ (ดาว = นับเป็นเรื่องสำคัญ), ธีมสว่าง/มืด/ตามเครื่อง, วันหยุดราชการ, ปี พ.ศ., วันเริ่มสัปดาห์, แจ้งเตือนค่าเริ่มต้น, สรุปเช้า |

ปุ่ม + มุมขวาล่างใช้จดเรื่องใหม่ในวันที่กำลังดูอยู่

## เรื่องที่ควรรู้

- **ทำซ้ำ** (ทุกวัน/สัปดาห์/เดือน/ปี) ติ๊กเสร็จแยกทีละครั้ง ถ้าตั้งวันที่ 31 ทุกเดือน เดือนที่ไม่มีวันที่ 31 จะเลื่อนมาเป็นวันสุดท้ายของเดือน
- **แจ้งเตือน** เรื่องที่ไม่ระบุเวลาจะนับเวลาเป็น 09:00 ถ้าตั้ง “เตือนซ้ำ” จะเตือนทุกชั่วโมงจนกว่าจะติ๊กเสร็จ (นานสุด 24 ชม.)
  เครื่องที่เปิด push ไว้จะรับจากเซิร์ฟเวอร์ ส่วนเครื่องอื่นจะเตือนเองเฉพาะตอนเปิดแอปค้างไว้
- **สรุปเช้า** ส่งครั้งเดียวต่อวันในช่วง 07:30–12:00 ตามเขตเวลาในหน้าตั้งค่า
- **วันหยุดราชการ** มีเฉพาะวันที่ตรงกันทุกปี วันพระ (มาฆบูชา วิสาขบูชา อาสาฬหบูชา เข้าพรรษา) และวันหยุดชดเชยยังไม่มี แก้ได้ใน `static/js/holidays.js`
- **วิดเจ็ต** เว็บแอปสร้างวิดเจ็ตบนหน้าจอโทรศัพท์ไม่ได้ แต่เพิ่มไอคอนไว้ที่หน้าจอหลักได้ (ดูหน้าตั้งค่า → วิดเจ็ตหน้าจอ)
- ฐานข้อมูลจากเวอร์ชันแรก (ที่มี priority/สี) จะแปลงให้อัตโนมัติตอนเปิดเซิร์ฟเวอร์ บันทึกที่เคยตั้งเป็น “สำคัญมาก” จะย้ายไปอยู่หมวด “สำคัญ”

## โครงสร้าง

```
server.py            HTTP server + JSON API + SQLite (รวมการคำนวณวันที่ทำซ้ำ, รหัสผ่าน, session)
push.py              Web Push และรอบเช็กแจ้งเตือนทุกนาที
backup.py            สำรอง/กู้คืนข้อมูล
Dockerfile, docker-compose.yml, Caddyfile, .env.example   สำหรับขึ้น VPS (ดู DEPLOY.md)
static/sw.js         service worker: ออฟไลน์ + รับ push
schema.sql           ตาราง categories, notes, completions, checklist, attachments, settings
static/index.html    โครงหน้า
static/style.css     สี (ตัวแปร --… บนสุดของไฟล์), ฟอนต์ + โหมดมืด
static/js/main.js    router (#/…), แถบเมนู, ปุ่ม +
static/js/views/     หน้าแต่ละหน้า
static/js/sheets.js  หน้าต่างเลื่อนขึ้น: จดเรื่องใหม่, แจ้งเตือน/ทำซ้ำ, เลือกหมวด
static/js/reminders.js  แจ้งเตือนและสรุปเช้า
tests/test_api.py    เทสต์ API, ล็อกอิน, กฎการแจ้งเตือน, การทำซ้ำ, ไฟล์แนบ, การแปลงฐานข้อมูล
```
