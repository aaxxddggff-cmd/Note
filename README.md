# สมุดสิ่งสำคัญ

แอปไว้จดเรื่องที่ห้ามลืม ผูกกับปฏิทิน มีแจ้งเตือน เช็กลิสต์ แนบไฟล์ได้ ตั้งให้เรื่องไหนทำซ้ำทุกวัน/สัปดาห์/เดือน/ปีก็ได้
ทำเป็นเว็บแอปธรรมดา แต่ติดตั้งลงมือถือได้เหมือนแอปทั่วไป และใช้ได้หลายคน ใครสมัครก็เห็นแค่ข้อมูลของตัวเอง

ตัวเซิร์ฟเวอร์เขียนด้วย Python ล้วน ๆ กับ SQLite ไม่ต้องลงอะไรเพิ่มก็รันได้

## ลองรันบนเครื่อง

```sh
python3 server.py
```

แล้วเปิด http://localhost:8001 กดสมัครสมาชิกได้เลย

อยากให้แจ้งเตือนเด้งได้ตอนปิดแอปด้วย ต้องลง `pip install -r requirements.txt` เพิ่ม (ถ้าไม่ลง แอปก็ยังเตือนได้ แต่เฉพาะตอนเปิดหน้าเว็บค้างไว้)

รันเทสต์:

```sh
python3 -m unittest discover -s tests -v
```

## เอาขึ้นเซิร์ฟเวอร์จริง

ใช้ Docker กับ Caddy (ทำ HTTPS ให้เอง) ขั้นตอนทั้งหมดอยู่ใน [DEPLOY.md](DEPLOY.md)
ก่อนชวนคนอื่นมาใช้ อย่าลืมแก้หน้า `static/privacy.html` ให้เป็นข้อมูลของตัวเอง และตั้ง SMTP ไว้ส่งอีเมลลืมรหัสผ่าน

คำสั่งสำหรับคนดูแลเซิร์ฟเวอร์:

```sh
python3 server.py --users                  # ดูว่ามีใครสมัครบ้าง
python3 server.py --reset-password EMAIL   # ตั้งรหัสใหม่ให้คนที่ลืม
python3 server.py --create-user EMAIL      # สร้างบัญชีให้ (กรณีปิดรับสมัคร ALLOW_SIGNUP=0)
python3 server.py --delete-user EMAIL
python3 backup.py                          # สำรองข้อมูลตอนนี้เลย
```

ค่าที่ตั้งผ่าน environment ได้ดูใน `.env.example`

## ข้อจำกัดที่รู้อยู่

- วันหยุดราชการมีแค่วันที่ตายตัว (ปีใหม่ สงกรานต์ วันแม่ ฯลฯ) ยังไม่มีวันพระตามจันทรคติกับวันหยุดชดเชย เพิ่มเองได้ใน `static/js/holidays.js`
- iPhone จะรับแจ้งเตือนได้ต้องเพิ่มแอปไว้หน้าจอโฮมก่อน และต้องเป็น iOS 16.4 ขึ้นไป
- ทำวิดเจ็ตบนหน้าจอโทรศัพท์ไม่ได้ เพราะเป็นเว็บแอป
- ตอนออฟไลน์เปิดดูของที่เคยโหลดไว้ได้ แต่แก้ไขไม่ได้
- เรื่องที่ไม่ใส่เวลา ระบบถือว่าเป็น 09:00 เวลาคำนวณแจ้งเตือน

## ไฟล์หลัก ๆ

```
server.py         เซิร์ฟเวอร์ + API + ฐานข้อมูล
push.py           ส่งแจ้งเตือนแบบ push
backup.py         สำรอง / กู้คืนข้อมูล
schema.sql        โครงตาราง
static/           หน้าเว็บทั้งหมด (js/views/ คือแต่ละหน้า, style.css คือสีกับฟอนต์)
tests/            เทสต์
```

ข้อมูลจริงเก็บใน `data.db` ไฟล์แนบอยู่ใน `uploads/` ข้อมูลสำรองอยู่ใน `backups/` ทั้งสามอย่างนี้ไม่ได้อยู่ใน git
